# 위시 퍼즐 (saving-puzzle)

사고 싶은 물건과 금액을 넣으면 **언제 살 수 있는지 계산**해 주고, 저금할 때마다 **물건 그림이 무작위로 열리는** 저금 게임 웹페이지예요.

## 열어 보는 방법

`index.html` 파일을 더블클릭하면 브라우저(크롬, 엣지 등)에서 바로 열려요. 설치나 회원가입은 필요 없어요.

## 주요 기능

- 목표 여러 개 등록 (물건 이름, 사고 싶은 이유, 상품 가격, 현재 모은 돈, 매달 모을 돈)
- 상품 링크와 사진(선택). 사진을 올리면 퍼즐 그림이 돼요
- 걸리는 기간과 달성 예정일 계산
- 모은 돈의 비율만큼 그림이 무작위로 열리는 퍼즐
- 정기납입일을 정하면 납입일마다 자동 기록 (정기 납입), 날짜·항목·금액으로 직접 기록 (상시 납입)
- 기록 한 줄 지우기, 모두 지우기, 복원
- 금액을 바꿔 보면 기간이 어떻게 달라지는지 비교
- 공유 링크: 목표 하나를 링크로 보내면 받는 사람이 읽기 전용으로 볼 수 있어요
- 백업 저장 / 불러오기

## 데이터는 어디에 저장되나요?

내 브라우저 안에만 저장돼요. 서버로 보내지 않아요. 다른 기기에서는 보이지 않고, 브라우저 기록을 지우면 사라져요. 홈 화면의 **백업 저장**으로 파일을 만들어 두면 옮기거나 되살릴 수 있어요.
